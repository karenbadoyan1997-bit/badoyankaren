# Формат бизнес-требования (скил Claude Code)

Мини-инструмент курса ACA «AI in Product Management» — демонстрация того, как
устроены **скилы Claude Code**: переиспользуемые инструкции, которые Claude
сам подключает в подходящий момент, без повторного объяснения каждый раз.

## Что делает

Когда я прошу написать бизнес-требования к системе, Claude формулирует каждое
требование одним предложением по шаблону:

> Необходимо создать возможность \<что именно и для кого/зачем\>.

Например:
- Необходимо создать возможность загружать несколько файлов выписок одновременно.
- Необходимо создать возможность фильтровать операции по диапазону дат.

## Зачем

Раньше формат приходилось напоминать каждый раз, когда просишь требования.
Скил решает это один раз — дальше Claude применяет его сам, в любой задаче
на формулировку требований.

## Где лежит рабочая версия

Сама инструкция для Claude (техническая часть) — не здесь, а в
[`.claude/skills/business-requirement-format/SKILL.md`](../../.claude/skills/business-requirement-format/SKILL.md).
Эта папка — только описание «что это и зачем» для курса, по общей структуре
репозитория (см. корневой `README.md`).

Есть и вторая, личная копия — работает не только в этом репозитории, а во всех
проектах Claude Code на этом аккаунте.
