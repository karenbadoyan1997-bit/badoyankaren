# Мастерская Карена — ACA "AI in Product Management"

Рабочее пространство для курса ACA. Здесь собираются учебные проекты, отдельные
прикладные навыки (мини-инструменты) и доведённые до готового вида продукты,
которые появляются по ходу курса.

## Кто я и как я работаю с этим репозиторием

Я — IT бизнес-аналитик с большим опытом в банковской сфере, веду проекты много
лет. Раньше писал код на C++/C#, но сейчас сознательно не хочу сам погружаться
в код: постановку, идеи и требования формулирую словами (по-русски или
по-английски), а всю техническую реализацию — код, структуру, тесты, деплой —
берёт на себя Claude Code.

Иначе говоря: я — продакт/аналитик и заказчик, Claude — исполнитель и разработчик.

## Структура репозитория

- `projects/` — учебные проекты и задания курса. Каждый проект — отдельная
  папка с кратким README: цель, что должно получиться, статус.
- `skills/` — небольшие прикладные навыки/утилиты, которые не тянут на полноценный
  продукт, но полезны сами по себе (скрипт, шаблон, чек-лист, мини-инструмент).
- `products/` — то, что доведено до вида законченного продукта: с описанием,
  понятным неспециалисту, и готовое к демонстрации или использованию.

Внутри каждой папки — свои подпапки по названию проекта/навыка/продукта, например:

```
projects/
  01-ai-feature-prioritization/
    README.md
skills/
  meeting-notes-summarizer/
    README.md
products/
```

## Как добавляем новую работу

1. Описываете идею простыми словами — что нужно, для кого, какой результат
   считается успехом.
2. Вместе выбираем, куда это относится: `projects`, `skills` или `products`.
3. Создаётся папка с README (что это и зачем) и реализация внутри неё.
4. Изменения фиксируются в git с понятным описанием.
