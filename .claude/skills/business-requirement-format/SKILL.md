# Формат бизнес-требования

Каждое требование формулируется одним предложением по шаблону:

> Необходимо создать возможность <что именно и для кого/зачем>.

Примеры:
- Необходимо создать возможность загружать несколько файлов выписок одновременно.
- Необходимо создать возможность фильтровать операции по диапазону дат.

Не используй другие формулировки («система должна», «пользователь может» и т.п.) — только этот шаблон, если явно не попросили иначе.
