# Персональный финансовый ассистент — MVP

Учебный проект курса ACA «AI in Product Management». Веб-система, которая
анализирует банковские выписки пользователя, находит интересные паттерны в
тратах и отвечает на вопросы о них в чате.

## Статус: MVP на синтетических данных

Первая версия — обкатка на сгенерированных данных, чтобы проверить продуктовую
гипотезу и интерфейс до подключения реальных выписок и настоящего ИИ-агента.

## Что уже умеет

- **Загрузка** — перетаскиванием (drag&drop) или выбором файла, можно сразу
  несколько CSV (например, по одному на счёт — они объединятся в один набор
  данных), либо сгенерированные синтетические данные для демонстрации.
  Поддерживаемый формат — CSV (`date, merchant, category, amount, currency, account`).
  XLS/XLSX и PDF пока не поддерживаются (см. «Дальше»).
- **Валюта** — армянский драм (AMD).
- **Дашборд** — сводка (расходы/доходы/баланс/средние траты в месяц), траты по
  категориям, динамика доходов и расходов по месяцам.
- **Найденные паттерны** — автоматически: регулярные платежи/подписки, категории
  с быстрым ростом трат, подозрительные задвоенные списания, необычно крупные операции.
- **Чат с агентом** — отвечает на вопросы по-русски («на что я чаще всего трачу
  деньги», «какие у меня подписки», «есть ли что-то подозрительное», «какой у
  меня баланс» и т.д.). Если на сервере настроен ключ Claude API — отвечает
  настоящая модель; если нет — работает шаблонный режим (см. ниже).

## Архитектурное решение: приватность данных

Загруженные выписки, их разбор и вся аналитика обрабатываются и хранятся
**только в браузере пользователя** (localStorage) — само приложение не имеет
бэкенда, который видит эти данные. Единственное исключение — чат с ИИ: когда
вы задаёте вопрос, вопрос и **уже посчитанная сводка** (категории, суммы,
тренды — не сырой список операций целиком) отправляются на сервер приложения,
который пересылает их в Claude API, чтобы получить ответ. Ключ Claude API
хранится только на сервере и никогда не передаётся в браузер.

## Чат-агент: два режима

- **Базовый режим (по умолчанию)** — шаблонный "агент": подбирает готовый
  ответ по ключевым словам в вопросе на основе аналитики (`src/lib/chatEngine.ts`).
  Работает сразу, без ключей.
- **Режим с ИИ** — задаёте `ANTHROPIC_API_KEY` на сервере (см. `.env.local.example`),
  и `/api/chat` (`src/app/api/chat/route.ts`) начинает отвечать настоящей моделью
  Claude, свободно понимая вопросы. Если ключ не задан или запрос не удался —
  интерфейс автоматически и незаметно для пользователя откатывается на базовый
  режим (индикатор в шапке чата показывает, какой режим сейчас активен).

## Как запустить

```bash
npm install
npm run dev
```

Открыть http://localhost:3000, нажать «Использовать синтетические данные» на
вкладке «Загрузка», затем посмотреть «Дашборд» и задать вопросы во вкладке
«Чат с агентом».

Чтобы включить настоящего ИИ-агента: скопируйте `.env.local.example` в
`.env.local`, вставьте ключ с https://console.anthropic.com/settings/keys,
перезапустите `npm run dev`.

## Структура кода

```
src/
  lib/
    types.ts        — модель данных (счета, транзакции)
    synthetic.ts     — генератор синтетических выписок с заложенными паттернами
    csv.ts           — парсинг/экспорт CSV
    analysis.ts      — вся аналитика: категории, тренды, подписки, аномалии
    chatEngine.ts     — шаблонный агент чата (MVP)
    store.tsx        — состояние приложения (React context + localStorage)
    palette.ts        — цветовая палитра графиков (light/dark)
  components/         — UI: загрузка, дашборд, графики, чат
```
